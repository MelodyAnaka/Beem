# beem website

Open `index.html` in a browser to preview. Upload the whole folder to any static host (Netlify, Vercel, GitHub Pages, cPanel).

Pages: index.html (home), shop.html, about.html, waitlist.html
Code: css/style.css, js/main.js, js/waitlist.js

## Collecting waitlist sign-ups
Open js/waitlist.js and paste a form endpoint into ENDPOINT (e.g. a Formspree URL).
Until then, sign-ups are only saved in the visitor's own browser and you will NOT receive them.

## Things to confirm
- Shade names (Milk, Petal, Merlot / Soft Nude, Rosé, Berry, Merlot) are placeholders.
- hello@beem.com and the Instagram link in the footer are placeholders.
